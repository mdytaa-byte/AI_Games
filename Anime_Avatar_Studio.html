How to use Anime Avatar Studio

Build a Japanese lesson character, give them dialogue, then project or export. The character is a vector illustration you can customize; the classroom tools around it are for teaching.

  • Cast: Variants A, B, and C are three characters you can switch while keeping a lesson scene. Save a finished student to the browser library, then click their card to load them back.
  • Dialogue: Write Japanese with optional furigana like 先生(せんせい). Use ◀ ▶ on the speech bubble to step through a conversation, and 🔊 to hear Japanese speech.
  • Present: Hide the editor and show only the character and dialogue — useful on a classroom projector. Press P to enter or exit.
  • Export: PNG and SVG download the character (optionally with the scene). Lesson Card makes a simple HTML slide with the portrait and lines. Open Project reloads a saved JSON file.
  • Look: Body type, face, hair, outfit, and expression all feed the same illustration. Custom color pickers sit next to the palettes when you need a specific shade.

Shortcuts: Ctrl+Z undo · Ctrl+Y redo · Ctrl+S save character · P present
