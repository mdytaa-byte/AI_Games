# Willkommen in Kleinhausen

A first-year German course in a single town. Students live in Kleinhausen as a guest student (first person), complete **16 story episodes**, and work toward **ACTFL Novice High** in reading, writing, listening, and speaking.

Play: open [`kleinhausen/index.html`](kleinhausen/index.html) or the GitHub Pages site root (redirects into the town).

Canvas: see [`kleinhausen/CANVAS.md`](kleinhausen/CANVAS.md).

Standalone praxis games from earlier in this repo (photo hunt, courier, wardrobe, supermarket, department store, chat, speaking partner) are now missions inside the episodes, copied under `kleinhausen/praxis/`. Original files remain at the repository root so old links still work.

## Johann: AI German tutor

[`johann/`](johann/) holds **Johann**, a single-file AI German tutor that students can pair with any German course (Kleinhausen, a textbook class, AP or IB German, exam prep, or an app). He offers conversation, questions, writing feedback, vocabulary drills, role-play, and test prep, and he coaches students without doing their work for them. Teachers can share a course code to set him up for a class. See [`johann/README.md`](johann/README.md).
