Method A — WordPress.com (recommended)

Fastest path: one Custom HTML paste.

  1. In WP Admin, go to Pages → Add New. Title it Welcome or Home.
  2. Add a Custom HTML block and paste the entire contents of wordpress/custom-html-with-styles.html.
  3. If WordPress strips the <style> tag, paste wordpress/splash-markup.html into the Custom HTML block instead, then paste wordpress/additional.css into Appearance → Customize → Additional CSS.
  4. In the page sidebar, choose a full-width or blank template if your theme offers one. Hide the page title if there is a title toggle.
  5. Publish the page.
  6. Go to Settings → Reading. Set “Your homepage displays” to A static page and choose the page you just created.
  7. If the theme header still shows, Additional CSS already includes a body:has(.amy-splash) rule to hide block-theme header, footer, and the page title.

Method B — Plugin + shortcode (self-hosted or WP.com Business)

  1. Upload wordpress-plugin/amy-author-splash.zip in WP Admin under Plugins → Add New → Upload Plugin. Activate it. (Or zip the folder yourself so amy-author-splash.php is at the top of the archive.)
  2. Create a page whose only content is the shortcode [amy_splash].
  3. Set that page as the homepage under Settings → Reading.
