Put Brightbarrow Press on WordPress

This is a simple imprint homepage: logo, a short manifesto, and a mailing list. Your live author site is WordPress.com, so Method A is the fastest path. Use Method B if you later move to self-hosted WordPress or a WordPress.com Business plan that allows plugins.

Method A — WordPress.com (recommended)

Create a new WordPress.com site for the imprint, or paste this as a new homepage on an existing site.

  1. In WP Admin, go to Pages → Add New. Title it Home or Brightbarrow Press.
  2. Add a Custom HTML block and paste the entire contents of wordpress/custom-html-with-styles.html.
  3. If WordPress strips the <style> tag, paste wordpress/splash-markup.html into the Custom HTML block instead, then paste wordpress/additional.css into Appearance → Customize → Additional CSS.
  4. In the page sidebar, choose a full-width or blank template if your theme offers one. Hide the page title if there is a title toggle.
  5. Publish the page.
  6. Go to Settings → Reading. Set “Your homepage displays” to A static page and choose the page you just created.
  7. If you created a new WordPress.com site for the imprint, open the Custom HTML and replace the hidden blog_id value with that site’s ID so the mailing list belongs to Brightbarrow, not the author site. Until then, the form uses the existing reader list at authormichaelyoung.com.

Method B — Plugin + shortcode (self-hosted or WP.com Business)

  1. Upload wordpress-plugin/brightbarrow-press.zip in WP Admin under Plugins → Add New → Upload Plugin. Activate it.
  2. Create a page whose only content is [brightbarrow_press].
  3. Set that page as the homepage under Settings → Reading.

Logo

The page includes a web recreation of the Brightbarrow mark so it stays sharp on any screen. If you would rather use the original file you designed, upload it to the WordPress Media Library and swap the inline SVG in the hero for an <img> tag pointing at that file.
