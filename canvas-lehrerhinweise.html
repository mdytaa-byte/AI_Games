Canvas LMS — so kommt 3D in den Kurs

Jedes neue Spiel ist eine komplette HTML-Seite: German-first, Englisch-Glossen, Vorlesen, hoher Kontrast, Funkmodus ohne WebGL, Abschlusscode zum Einfügen in eine Aufgabe. Es werden keine Cookies und kein localStorage benutzt.

Zwei Wege

  1. Empfohlen: GitHub Pages verlinken oder iframen. WebGL und Pointer-Lock funktionieren so am ehesten. Studierende dürfen „in neuem Tab öffnen“.
  2. Einzeldatei: Datei aus dem Ordner canvas/ als Datei in Canvas hochladen (eine HTML-Datei, Three.js ist schon drin). Manche Schul-iframes blocken WebGL — dann Funkmodus nutzen.
Beispiel-iframe (URL nach dem Pages-Deploy anpassen): 
<iframe
  src="https://mdytaa-byte.github.io/AI_Games/spiele/cafe-sonnenkorn.html"
  width="100%" height="720"
  allow="fullscreen"
  title="Café Sonnenkorn"></iframe>

Aufgabe in Canvas (Textvorlage)

Spiele das 3D-Deutschspiel bis zum Ende (oder im Funkmodus).
Gib deinen Namen im Spiel genau so ein wie in Canvas.
Kopiere den Abschlusscode in dieses Abgabefeld.

Wenn das 3D-Bild nicht lädt: Button „Funkmodus“ — dieselben Aufgaben.

Punkte

Jede Mission hat fünf Aufgaben, je 2 Punkte beim ersten Versuch, 1 Punkt nach Korrektur. Der Code enthält den Prozentwert. Schreiben-Aufgaben (Fest, Museum, See) verlangen Mindestwortzahl und Schlüsselwörter (habe, finde, weil).

Neu bündeln

python3 scripts/build-canvas.py
