Stadtplan

Für Lehrkräfte · nicht für die Klasse

Ein Blatt für Canvas: was jedes Spiel übt, welcher Code zurückkommt, und wie du ihn prüfst. Die Lernenden öffnen den Stadtplan oder eine einzelne HTML-Datei. Kein Konto, keine Cookies — Fortschritt gilt nur für den Besuch. One sheet for Canvas: what each game practises, which code comes back, and how to verify it. Students open the town map or a single HTML file. No accounts, no cookies.

So kommen die Codes an

  1. Spiel zu Ende spielen.
  2. Namen eingeben — denselben Namen wie in Canvas.
  3. Code kopieren (KH-…) und in die Aufgabe kleben.

Finish → type the Canvas name → paste the KH- code into the assignment.

So prüfst du einen Code

  1. Dasselbe Spiel öffnen.
  2. Unten: Für Lehrkräfte: Code prüfen.
  3. Name + Code. Die Prüfsumme hängt am Namen — vertauschte Namen fallen auf.

Open the same game → teacher details → name + code. The checksum is tied to the name.

Was „gut“ heißt

75 %+ oder das vorgesehene Ende (Held, Nacht, alle Stempel) gilt als geschafft. Unter 50 %: noch einmal, Erklärungen lesen. Codes sind kein Hochsicherheitsschloss — der Quelltext ist lesbar.

Treat 75%+ or the intended ending as a pass. Below 50%: replay. Codes deter casual fakes; they are not crypto.

Kurz notiert

  • Englisch-Glossen sind an, bis die Klasse sie ausknipst — gut für den ersten Durchgang, später aus.
  • Fahrkartenautomat: Übungs-PIN 1234 steht auch auf dem Startbildschirm.
  • Amt: Datum TT.MM.JJJJ, Vorname/Nachname nicht tauschen, PLZ 55299.
  • Café und Amt: grobes du zum Personal ist falsch.
  • Canva: eine HTML-Datei in Canva Code, oder GitHub Pages einbetten. Vorlesen kann in iframes stumm bleiben.
