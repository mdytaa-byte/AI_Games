So funktioniert's

Das Spiel übt den Imperativ — Befehle auf Deutsch.

This game practices the German imperative — giving commands.
  • Befehle geben: Lies den Auftrag. Schalte „Simon sagt“ ein oder aus. Wähle die Form, die zur Person passt.
  • Eine Person → du (Wink!). Zwei / beide → ihr (Winkt!). Frau Berg → Sie (Winken Sie!).
  • Ohne „Simon sagt“ bleiben Mira, Otto und Frau Berg stehen. Mit den Worten führen sie den Befehl aus.
  • Simon sagt (klassisch): Tippe die Aktion nur, wenn der Fuchs „Simon sagt“ voranschickt.
  • Noch mal hören spricht den letzten Befehl erneut. Vollbild eignet sich für den Beamer. Spickzettel drucken gibt den Imperativ-Zettel auf Papier.
  • Tastatur: S = Simon sagt ein/aus · 1–9 = Befehl · Esc = Hilfe schließen.
One person → du. Two people → ihr. Frau Berg (formal) → Sie. Without “Simon sagt”, nobody moves. Keyboard: S toggles Simon, number keys pick a command.
